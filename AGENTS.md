# Project Instructions

## Project Overview
This project follows the requirements
defined in PRD.md.

## Development Rules
- Always follow PRD.md.
- Do not implement features outside the PRD
  without asking for approval.
- Follow the existing project architecture.
- Write clean and maintainable code.
- Avoid unnecessary dependencies.

## Workflow
1. Analyze before implementing.
2. Work incrementally.
3. Test every implemented feature.
4. Report modified files.
5. Never silently change existing functionality.

## Important
If requirements are ambiguous, ask before coding.
